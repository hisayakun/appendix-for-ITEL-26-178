## Generative AI settings in the experiment (January 29, 2024)

- **Client**: BetterChatGPT (https://bettergpt.chat), an open-source ChatGPT client (https://github.com/ztjhz/BetterChatGPT). The students used the hosted web app; the latest commit to the repository before the experiment was `8627cf0` (January 23, 2024).
- **Model**: The dialogue histories of the 28 students who used gpt-4 record the model name `gpt-4`. The snapshot that generated the responses was not recorded. OpenAI announced that the model name `gpt-4` would point to the snapshot `gpt-4-0613` from June 27, 2023 ([OpenAI, June 13, 2023](https://openai.com/index/function-calling-and-other-api-updates/)), and OpenAI's model documentation lists `gpt-4-0613` as the default snapshot of GPT-4 ([OpenAI, accessed October 4, 2026](https://developers.openai.com/api/docs/models/gpt-4)). The responses were therefore most likely generated by `gpt-4-0613`.
- **Parameters** (as recorded in the dialogue histories): temperature = 0, top_p = 1, presence_penalty = 0, frequency_penalty = 0. The BetterChatGPT "max tokens" setting was 8,192 (4,096 for one student). In this version, BetterChatGPT did not send this value to the API as `max_tokens`; it used the value to limit the length of the conversation history sent to the API (`src/api/api.ts` and `src/hooks/useSubmit.ts` at commit `8627cf0`).
- **System message**: The BetterChatGPT default, which was displayed in Japanese: 「あなたはChatGPT、OpenAIによって訓練された大規模な言語モデルです。ユーザーの指示に注意深く耳を傾けてください。Markdownを使って応答してください。」 (English original in BetterChatGPT: "You are ChatGPT, a large language model trained by OpenAI. Carefully heed the user's instructions. Respond using Markdown.")
- **Quiz creation prompt**: The prompt was not set as the system message. Each student entered it as the first user message and then created quizzes by freely interacting with GenAI in a single conversation.
